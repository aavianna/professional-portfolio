# Professional Portfolio | Front-end Developer

Olá! Sou desenvolvedor Front-end, com experiência no desenvolvimento, manutenção e evolução de aplicações web em produção.

Ao longo da minha trajetória profissional, participei de projetos de diferentes segmentos, trabalhando com interfaces interativas, aplicações de alta disponibilidade, integrações com APIs e evolução de plataformas digitais.

Este repositório reúne alguns dos projetos dos quais participei profissionalmente, apresentando seus objetivos, tecnologias utilizadas e respectivas aplicações em produção.
